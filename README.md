## What I'm working on

I'm developing an **STM32-based UWB/BLE cooperative low-power access system** for my graduation project, bringing together:

- **STM32 & FreeRTOS** for task scheduling, peripheral control, and sleep/wake management.
- **UWB/BLE** for ranging and low-power wireless access.
- **Custom PCB design** and switched power domains for hardware integration and power management.
- Experimental evaluation of power consumption, communication latency, and connection reliability.
